## 🏛️ Descripción Institucional

Sitio web oficial de **NIVAL Sciences**, desarrollado con base en el documento fundacional *Identidad Estratégica y Proyección Institucional*. 

El ecosistema articula sus servicios a través de **9 capas institucionales**:

1. **Presentación Institucional:** Acceso y articulación del ecosistema bajo la premisa de anticiparse a la salud.
2. **Nosotros:** Concepto institucional, misión, visión, valores y modelo de trabajo.
3. **Laboratorio Clínico:** Primera unidad operativa consolidada, catálogo de perfiles, doble verificación analítica y guía técnica de preparación al paciente.
4. **Prevención y Calidad de Vida:** Programas de tamizaje periódico, jornadas de salud integrales y recursos de autocuidado.
5. **Asesoría para Personas:** Servicios de orientación, lectura de resultados y definición de rutas de atención.
6. **Soluciones para Empresas:** Asesoría corporativa en salud ocupacional, jornadas in-company y programas continuos.
7. **Formación y Capacitación:** Cursos y talleres técnicos para profesionales, comités laborales y comunidad, con proyección de Campus Digital.
8. **Innovación y Tecnología:** Microaplicaciones, herramientas digitales, interoperabilidad y metas institucionales por etapas (0 a 36 meses).
9. **Contacto y Atención:** Directorio de sede, horarios oficiales y canales formales de enlace.

## 💻 Desarrollo Local

Para ejecutar el proyecto en tu entorno local:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo local
npm run dev

# 3. Compilar para producción
npm run build
```
